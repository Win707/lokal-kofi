# Lokal Kofi

A responsive concept website for **Lokal Kofi**, a neighborhood coffee shop in Dologon, Bukidnon, Philippines. Built as a web development portfolio project by [Erwin Leonardia](mailto:erwin.leonardia.job@gmail.com).

> **Note:** This is a concept project and not the official website of Lokal Kofi. Shop details are placeholders until confirmed by the owner.

## Features

- Clean, readable layout with generous spacing and a calm, classy look
- Menu section with category filters and drink size prices
- Mobile-friendly navigation
- Fully responsive from 360px phones to large desktops
- Semantic HTML, keyboard focus styles, and accessible labels
- Static site with no build step or dependencies

## Tech stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript (menu filters, size prices, mobile navigation)
- Google Fonts (typography)
- Unsplash (hero photo)
