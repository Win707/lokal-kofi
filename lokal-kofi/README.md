# Lokal Kofi

A responsive website for Lokal Kofi, a neighborhood coffee shop in Bukidnon, Philippines. It uses plain HTML and CSS with a small JavaScript file for the menu filters, drink size prices, and mobile navigation. The hero photo is loaded from Unsplash, and typography uses Google Fonts.

## Run locally

Open `index.html` in a browser, or open this folder in VS Code and launch `index.html` with the Live Server extension. No build step or package installation is needed.

## Deploy on Vercel

1. Import the repository into Vercel.
2. Set the project root to `lokal-kofi` (or to this folder if it is the repository root).
3. Choose the Other framework preset and leave the build command and output directory empty; Vercel will serve the static files from this folder.
4. Deploy.
